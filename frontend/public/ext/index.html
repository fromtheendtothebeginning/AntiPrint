扫码直接安装 推荐

用 AntiSIT「拓展」页右上角的扫一扫，扫这个安装码

  1. 打开 AntiSIT → 底栏「拓展」→ 右上角 扫一扫
  2. 扫描上面的二维码，界面底部出现「下载拓展」
  3. 确认安装包信息（AntiPrint 管理 v1.1.2）与权限：本机存储 / 联网 / 通知
  4. 安装完成后打开拓展，用管理员账号登录即可

安装码自带 sha256（f9a35f83…a559a0），下载后校验不一致就不会安装。 新版 AntiSIT 已给扫码 / 本地安装的拓展开放联网，装完能直接连服务器。

第三方源安装 旧版 AntiSIT 用这个

如果你的 AntiSIT 还没有开放插件联网，扫码装上也会连不上服务器，请改用市场源安装：

  1. 「拓展」→ 顶部切到「市场」→「添加第三方源」
  2. 粘贴下面的源地址，核对指纹后再确认：
https://print.anticraft.top/market/
公钥指纹 0062-CC99-F646

添加后在「市场」里安装「AntiPrint 管理」，之后有新版本会提示更新。

传输到手机安装

不方便扫码时：下载安装包，在「拓展 → + → 导入 Cordis 压缩包」里选择它。

下载 antiprint-admin-1.1.2.zip
装好后连不上服务器？
先确认拓展权限里有「联网」；旧版 AntiSIT 对本地导入的包会禁网，此时请按上面的「第三方源安装」重新装一次。
